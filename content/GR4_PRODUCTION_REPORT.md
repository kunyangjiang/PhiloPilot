## 2. 涵盖的哲学问题与论证

- **导读。** 八个中心问题（与任务书一致）；"本课一句话"；七种材料表；史料状况的说明（伊壁鸠鲁、早期斯多亚派、怀疑派、罗马斯多亚派各自的情况），明确提出"不能用罗马时期的斯多亚派著作当作早期学说的证据"；章节编号的说明；18 个术语的译名表。
- **第一部分。** 对"城邦衰落、哲学向内转"叙事的三点修正，包括明确说明"哲学不是到了亚里士多德以后才变得实践的"；花园、画廊、学园、吕克昂、犬儒；前 86 年以后哲学向罗马的扩散；逻辑、物理、伦理的整体性（第欧根尼·拉尔修 7.39—40 的动物、蛋、田地比喻；《主要学说》第 11 条）；犬儒的态度和史料可靠性的问题；第欧根尼 6.63 的"世界公民"及其两种读法；希帕基娅（6.96—98），包括其诡辩、回答特奥多罗斯的话，以及对这条材料"能证明什么、不能证明什么"的三点说明；阿多"作为生活方式的哲学"及其批评。
- **第二部分。** 哲学作为灵魂的医术；快乐是目的（《致美诺凯乌斯的信》128—129）；摇篮论证的重构和批评；"不是浪荡子的快乐"（131）；静态与动态的快乐（第欧根尼·拉尔修 10.136；《主要学说》第 3、18 条）；西塞罗的反驳和现代的几种读法；欲望的三分（127；《主要学说》第 15、29、30 条；《梵蒂冈格言集》第 25、33、71 条），附教学示例及其限度；实践智慧和德性的工具性地位（132；《主要学说》第 5 条），与斯多亚派的对照；原子论及其对伦理学的两个结论；对神的恐惧（123；《主要学说》第 1 条；卢克莱修 1.62—67、1.101）；对死亡的恐惧：经验论证和对称论证的重构（124—125；《主要学说》第 2 条；卢克莱修 3.830—831、3.972—975），内格尔的剥夺论证，对称论证的反驳，以及"死亡"的几种恐惧的分解；友爱（《主要学说》第 27 条；《梵蒂冈格言集》第 23、52 条，包括第 23 条的异文）及其理论难题；正义作为约定（《主要学说》第 31、33、34、35 条）及古革斯之戒式的反驳；远离公共生活；卢克莱修；"四味药"表和四点反驳。
- **第三部分。** 三个时期和史料问题（SVF）；斯多亚派命题逻辑与亚里士多德词项逻辑的对照（第欧根尼·拉尔修 7.80—81 的五种不可证明的推论）；印象、认可、把握（7.46、7.49；西塞罗《卢库卢斯》145 芝诺的手势）；物理学的四点概括；属己化（7.85—86）及其与伊壁鸠鲁派摇篮论证的对立；目的公式（7.87—88）；"唯一的善是德性"的论证重构（7.101—103）和反驳；优先选取之物（7.102—105）和价值等级表；弓箭手（西塞罗《论至善与至恶》3.22）；西塞罗"只是名词之争"的反驳和斯多亚派的回答；合宜的行为和正确的行为；智者和进步；激情的定义（7.110）、激情是判断（7.111）、四种激情的二乘二表；良好的情感（7.116）和两种"没有激情"（7.117）；第一阵冲动（盖利乌斯 19.1.15—18），并说明这是罗马时期的材料；对激情理论的两个反驳（一元论心理学；悲痛）和《手册》第 3 章；世界公民（《论至善与至恶》3.62—64；希洛克勒斯，转述）及其与犬儒的两点不同；塞涅卡（《书信》16.3、2.5、47.1）、爱比克泰德（《手册》1.1、1.5、5；《论说集》1.1.7）、马可·奥勒留（《沉思录》2.1、4.3）；早期与罗马时期的对照表；三种常见的误解。
- **第四部分。** 古代词汇（τὸ ἐφʼ ἡμῖν）与现代术语的区别；斯多亚派的命运（盖利乌斯 7.2.1—3）；二值原则论证（西塞罗《论命运》20—21）及伊壁鸠鲁和克律西波斯的对照；懒惰论证的重构（28—29）和"共同注定"的回答（30）；责任的反驳（盖利乌斯 7.2.5）；完全的原因和辅助的原因（《论命运》41）；圆柱（43；盖利乌斯 7.2.11）的重构；两个反驳（品格也被决定；比喻是否恰当）和西塞罗的评价（39）；伊壁鸠鲁的挑战（《致美诺凯乌斯的信》133—134）；偏斜（卢克莱修 2.217—224、2.251—258、2.289—293）的重构和三个困难；西塞罗的批评（《论命运》22）和卡尔涅阿德斯的中间立场（23）；说明这场"辩论"是西塞罗组织起来的，三方没有直接对话；古代立场与现代术语的对照表；博布齐恩和弗雷德的观点；三个开放的问题。
- **第五部分。** 塞克斯都的三种哲学（《皮浪学说纲要》1.1、1.3）；皮浪（第欧根尼·拉尔修 9.61—62）及关于他生活的两种相反的说法；阿尔克西拉乌斯（西塞罗《学园派》1.45）及两种解读；学园派对可把握的印象的攻击的重构；"不行动"的反驳和"合理的东西"；卡尔涅阿德斯的可信性（《卢库卢斯》99、104）和两种解读；埃奈西德穆和塞克斯都；怀疑论的定义（1.8）和关键术语（1.10），"悬置不是否定"；起源（1.12）和阿佩莱斯的海绵（1.28—29）；适度的感受（1.29—30）；十论式（1.36—37）表和一般结构；五论式（1.164、1.166、1.168、1.169）和阿格里帕三难困境的重构；标准的问题；怀疑派怎样生活（1.19、1.23—24、1.13）；"乡下人式"和"城里人式"之争；自我推翻的反驳（第欧根尼·拉尔修 9.104）；两种怀疑论的比较表和塞克斯都对阿尔克西拉乌斯的评价（1.226、1.232）；古代怀疑论不是笛卡尔的怀疑、不是今天的科学怀疑精神、不是虚无主义（并指出其保守性的弱点）。
- **第六部分。** 医生的比喻及其风险；三种诊断、三种药方的表，以及"用真的信念代替假的"与"不用任何信念代替信念"的区别；三派的"安宁"不同；练习表（八种，标明史料）和"预想"与"转移"的对立（西塞罗《图斯库卢姆论辩》3.29、3.30、3.33）；三个日常情境（考试失利、所爱的人重病、看到不公正）中三派可能的建议和每种建议的限度，标明是本章的推想；明确反对把三派合成一套"古代智慧"；欲望、情感、责任、共同体、政治五个问题的比较；"政治上的寂静主义"的批评；治疗的限度：不能代替医疗和心理治疗（三个理由，包括认知行为疗法的关系）、把痛苦归咎于受苦的人、外在的条件、爱与悲痛；对阿多和库珀之争的评价；结语总表，以及"三派不是可以随意挑选的选项"。

**核对方法。** 用一个脚本（在临时目录中，没有放进项目）把稿件中每一个原文块按省略号和诗行分段，去掉重音、标点和大小写后，在对应作品的数字本全文中查找；行内引用的希腊文短语另行检查。结果：105 个原文块、138 个分段全部找到；卢克莱修 3.972—975 有两段只在 Perseus 本中按字面找到，原因是 Munro 本扫描的光学识别文本在这两行有严重错误（"itera quara""teraporis""nostrara"），本课逐行对照扫描文本确认 Munro 本的读法与稿件一致。核对中发现并改正了三处稿件自己的错误：《主要学说》第 35 条的"一万次"（初稿误作"一千次"）；卢克莱修 2.218 漏了 Munro 本的"se"；爱比克泰德《论说集》1.1.7 的短语初稿写成了主格，已改回原文的宾格。

**数字本的错误，以及本课的改正**（均在注释中逐一说明）：《致美诺凯乌斯的信》127（"φυσι καὶ"）；《卢库卢斯》99（"esseCarneadi"）、145（"ilium"）；盖利乌斯 19.1.16（"συγκαταφέσεις"）；塞克斯都 1.3、1.8、1.10、1.13、1.28、1.29 的若干处。

**卢克莱修的异文。** Perseus 数字本的卢克莱修文件头没有记录所据印本，也没有写明授权，所以稿件的拉丁文一律从 Munro 本。核对中发现，Munro 本与 Perseus 本在所引段落中有几处异文，其中 2.257—258 最重要：Munro 本作"fatis avolsa potestas / … quo ducit quemque voluntas"，Perseus 本作"fatis avolsa voluntas / … quo ducit quemque voluptas"（Phase 9B 据 Munro 的校勘记更正：这是兰比努斯对调后的读法，不是抄本的读法；见注 55）。稿件从 Munro 本，并在注 55 中说明了两种读法及其意义上的差别。产品负责人或审读专家可能希望改从今天的通行读法，这需要另找一个可以使用的现代校勘本（见第 8 节）。

**只作转述、没有核对原文的段落**，在正文中标为"转述"，并在注释中写明"本课没有核对"。主要有：伊壁鸠鲁《致希罗多德的信》35—37、63—65；第欧根尼·拉尔修 7.72、7.132—160、10.29—34；西塞罗《论至善与至恶》第一、二、四卷的有关段落，《卢库卢斯》54—58、84—86；塞涅卡《论愤怒》3.36、《论闲暇》、《论幸福的生活》；塞克斯都《反数学家》7.16、7.158、7.166—189，《皮浪学说纲要》1.206、3.280—281；普鲁塔克、盖伦、斯托拜乌、佛提乌斯、波菲利中的转述；菲洛德穆的纸草；奥伊诺安达的铭文。

## 4. 术语

导读中的术语表列出 18 个译名。主要的选择和理由：

| 原词 | 本课译名 | 其他常见译法 | 理由 |
|---|---|---|---|
| ἀταραξία | 安宁；心灵不受纷扰 | 宁静、不动心 | "不动心"容易和斯多亚派的 ἀπάθεια 混淆；伊壁鸠鲁派和怀疑派都用这个词，用一个中性的"安宁"，正文再说明两派含义的不同 |
| ἀδιάφορα | 无关善恶之物 | 中性物、无所谓之物 | "无所谓"会造成"斯多亚派不在乎健康"的误解；"无关善恶"直接说出它的意思 |
| προηγμένα | 优先选取之物 | 可取之物、偏好的东西 | 保留"在选择中被放在前面"的意思，又不把它说成"善" |
| φαντασία | 印象 | 表象、呈现、幻象 | 不用"幻象"，因为它不意味着虚假 |
| συγκατάθεσις | 认可 | 赞同、同意 | "认可"更能表达"对一个印象说是"；正文中偶尔用"赞同"来翻译西塞罗的 adprobare / probatio |
| κατάληψις | 把握 | 认知、理解、领会 | 保留芝诺"握拳"比喻的字面意思 |
| πάθος | 激情 | 情感、情绪 | 斯多亚派的专门用法只指"过度的、错误的"情感；用"激情"与一般的"情感"区分开，这是全课的一个关键 |
| εὐπάθεια | 良好的情感 | 好情绪、善感 | |
| οἰκείωσις | 属己化 | 亲近、据为己有、归属 | 表达"认作属于自己的"这一过程 |
| τὸ ἐφʼ ἡμῖν | 取决于我们的 | 在我们权能之内的、我们能控制的 | 不译成"自由意志"，以免把现代的问题投射到古代 |

## 5. 计划中的视觉与互动教学设计（只是计划，没有实现）

本阶段不做 React 实现。任务书列了五个候选，下面建议做四个（按建议的优先顺序：B、A、D、C），第五个（E）不建议单独做，理由见 E。

### B. 斯多亚派印象与认可工作坊（Stoic Impression & Assent Workshop）

- **位置**：第三部分"印象、认可与把握"之后（芝诺手势表之后）；第三部分"激情：错误的判断"一节可以再次调用。
- **目标**：让读者亲手区分"印象"和"认可"，看到激情包含两个判断（"这是坏事"和"对此感到痛苦是恰当的"），并区分不由自主的第一阵反应和认可。
- **视觉构想**：一张情境卡（例如"收到一封措辞冷淡的邮件""海上突然起了风暴""朋友没有回消息"）。卡下是一条三段的流程：印象 → 检查 → 认可 / 拒绝 / 暂不判断。旁边一个小的手势图标，随阶段变化（张开的手、稍收拢、握拳），对应芝诺的手势（西塞罗《卢库卢斯》145）。
- **学习者操作**：
  1. 读情境卡，看到印象的文字（例如"他看不起我"）；
  2. 用《手册》1.5 的标准检查：这是关于取决于我们的东西吗？这个印象说的是事实，还是加上了"好 / 坏"的判断？
  3. 选择认可、拒绝或暂不判断；
  4. 在"风暴"情境中，先看到"脸色发白"（第一阵反应），再决定是否认可"这是可怕的坏事"。
- **反馈**：认可了带有善恶判断的印象时，显示由此产生的激情（按四种激情的二乘二表），以及斯多亚派会怎样分析；拒绝时，显示对应的良好情感（如果有）。在"风暴"情境中引用盖利乌斯 19.1.15—18 的原文和本章试译，并注明"这是公元 2 世纪的材料，转述的是罗马时期的斯多亚派"。
- **学术把关**：
  - 不给出"正确的情绪"，只展示斯多亚派的分析，并在每一张卡片的末尾加一个"对这个分析的反驳"的折叠说明（例如一元论心理学的问题、悲痛的问题）；
  - 不把它做成情绪管理工具；界面上有一行固定的说明："这是对一种古代理论的演示，不是心理辅导"；
  - 不收集或保存学习者的选择。
- **移动端 / 桌面**：桌面为左右两栏（情境卡与流程）；移动端改为分步向导（印象 → 检查 → 选择 → 分析），按钮不小于 44px。
- **最小实现**：一份情境 JSON（情境文字、印象文字、检查问题、各选择的结果、对应的原文出处）；一个 React 组件管理步骤状态；手势用三个内联 SVG。不需要图形库。

### A. 伊壁鸠鲁欲望探索器（Epicurean Desire Explorer）

- **位置**：第二部分"欲望的分类"一节，表格之后（可以替代或补充该表）。
- **目标**：让读者用伊壁鸠鲁自己的问题（《梵蒂冈格言集》第 71 条）来给欲望分类，体会分类的依据是"不满足时会不会痛苦"和"有没有自然的界限"，同时看到这一分类在今天应用时的限度。
- **视觉构想**：三个并列的区域（自然而必要 / 自然而不必要 / 空洞的），以及一组欲望卡片（"渴了想喝水""想吃一顿昂贵的大餐""想要一座自己的雕像""想要最新款的手机""想被所有人认可""想有一个可以倾诉的朋友"）。
- **学习者操作**：
  1. 选一张欲望卡；
  2. 回答两个问题："如果实现了，会怎样？如果没有实现，会怎样？"和"这个欲望有没有自然的终点？"（各有三个选项）；
  3. 根据回答，卡片落入一个区域；学习者也可以手动把卡片拖入或点选放入另一个区域，并看到说明。
- **反馈**：对古代的例子（水、昂贵的食物、花冠和雕像）显示《主要学说》第 29 条附注的原文和本章试译，注明附注很可能是后人加的；对现代的例子（手机、认可、朋友）显示"本章的看法"和"这一分类的限度"（社会条件改变了什么是"必要的"）；"朋友"卡片额外链接到友爱一节。
- **学术把关**：
  - 不说"伊壁鸠鲁要求你放弃不必要的欲望"：自然而不必要的欲望可以享受，只是不要依赖；
  - 现代例子都标"本章编的"；
  - 不评分，不保存。
- **移动端 / 桌面**：桌面为三栏加卡片池，可以拖动；移动端用点选代替拖动（选卡片 → 回答问题 → 显示结果），三个区域改为可折叠的列表。
- **最小实现**：一份欲望 JSON（文字、两个问题的选项与对应的分类、说明、原文引用）；一个 React 组件；布局用 CSS 网格。

### D. 怀疑派论式实验室（Skeptical Modes Laboratory）

- **位置**：第五部分"怀疑派的'论式'"一节，十论式表之后；五论式部分可以作为第二个模式。
- **目标**：让读者看到所有论式的共同结构（显现不同 → 无法判定 → 悬置），并亲手体验阿格里帕三难困境：为一个主张提供理由时，链条只有三种结局。
- **视觉构想**：
  - 模式一（十论式）：一个对象卡（蜂蜜、温水、方塔、一种习俗），下面是两到三个"观察者"（不同的动物、不同的人、不同的位置），每个观察者旁显示"对他显现为……"。中间一个"判定"按钮。
  - 模式二（五论式）：一个主张（例如"感觉是可靠的"）在顶部；学习者每给出一个理由，下面就长出一个新的节点，系统追问"这个理由的理由是什么？"；最后链条以三种方式之一结束：一直延伸（无穷）、停在一个没有理由的节点（假设）、连回到顶部（循环）。
- **学习者操作**：模式一中，学习者尝试选择"哪一个观察者是对的"，并给出理由；系统用另一个论式指出这个理由本身需要判定。模式二中，学习者从预设的理由中选择，搭出一条链。
- **反馈**：模式一中，在学习者选择之后显示"怀疑派会说：你选择的标准本身也有分歧……"，并引用《皮浪学说纲要》1.36 或 1.164 的原文；模式二中，链条以哪一种方式结束，就显示对应论式的原文（1.166、1.168 或 1.169）和本章试译。最后显示"悬置不是否定"的说明（1.10）。
- **学术把关**：
  - 明确说明论式的目的是悬置判断，不是证明"什么都不能知道"；
  - 在模式二末尾提示现代认识论对这一困境的三种回答（基础主义、融贯论、无穷主义），注明"现代的回答，不是古代的"；
  - 例子只用稿件中出现过的，或标"本章编的"。
- **移动端 / 桌面**：桌面模式一为对象在上、观察者横排；移动端观察者改为纵向卡片。模式二在桌面上是一棵向下生长的树，移动端改为纵向的步骤列表（每一步显示"理由 → 追问"）。
- **最小实现**：两份 JSON（论式例子；理由树，节点标明它导向的结局）；一个 React 组件，两个模式用标签页切换；树用嵌套的列表加 CSS 连线，不需要图形库。

### C. 命运与责任探索器（Fate & Responsibility Explorer）

- **位置**：第四部分"克律西波斯的回答：圆柱"之后；"偏斜"一节可以再次调用。
- **目标**：让读者分清懒惰论证中的"单纯的"和"共同注定的"事情，理解"完全的、主要的原因"和"辅助的、临近的原因"的区分，并比较三种立场（克律西波斯、伊壁鸠鲁派、卡尔涅阿德斯）对同一个行为的说明。
- **视觉构想**：
  - 第一屏：懒惰论证的五步重构，每一步是一张卡片；学习者点选"哪一步错了"。
  - 第二屏：一个斜坡上的圆柱和一个方块（简单的 SVG 动画）：同样被推一下，圆柱滚下去，方块停住。旁边标注"推 = 印象（辅助的原因）""形状 = 品格与认可（主要的原因）"。
  - 第三屏：一个行为（稿件中的"作弊"例子），三栏分别显示三种立场的说明。
- **学习者操作**：第一屏选择错误的步骤；第二屏切换"圆柱 / 方块"并点"推"；第三屏为每种立场回答"他要为此负责吗？为什么？"（选择题）。
- **反馈**：第一屏显示《论命运》30 的原文（共同注定）；第二屏显示《论命运》43 和盖利乌斯 7.2.11 的原文；第三屏在学习者作答后显示每种立场的理由、主要的反驳和"古代立场与现代术语"表的对应一行。
- **学术把关**：
  - 最后一屏固定显示"这个问题至今没有公认的答案"，不宣布胜负；
  - 偏斜一栏注明"证据主要来自卢克莱修和西塞罗"，并说明它是否对应每一个选择有争议；
  - 卡尔涅阿德斯一栏注明"只是西塞罗的转述"；
  - 现代术语只在最后作为对照出现，注明它们是近代以后的。
- **移动端 / 桌面**：三屏在桌面上横向翻页，在移动端纵向滚动；SVG 动画在"减少动态效果"设置下改为静态的前后两张图。
- **最小实现**：一份 JSON（五步论证、三种立场的说明与问题）；一个 React 组件；斜坡动画用 SVG 和 CSS transform，不需要物理引擎。

### E. 哲学生活方式比较（Philosophical Life Comparison）：不建议单独做

- **评估**：设想过一个"选一个情境，看三派的建议"的组件。不建议单独做，理由是：
  - 第六部分的三张情境表已经清楚，互动只是把表格变成点选；
  - 最大的风险是让读者以为三派是可以随意挑选、混合的"选项"，这正是稿件第六部分明确反对的；一个"选一个适合你的学派"式的界面会强化这种误解；
  - 情境中三派的"建议"都是本章的推想，做成互动组件后，容易被误当作古代文本的话。
- **如果产品负责人仍然希望做**：建议做成静态的、带标签页的情境比较卡（不加"推荐"或"测验"），每张卡片在显眼的位置标注"本章根据学说推想的建议，不是古代文本"，并且每一派的建议下面固定显示"这种建议的限度"。最小实现是一份 JSON 和一个标签页组件。

## 8. 主要的学术不确定之处

- **静态的快乐。** 伊壁鸠鲁的"静态的快乐"究竟是什么，现代学者有不同的读法；稿件列出了三种，不作选择（注 20）。
- **卢克莱修 2.257—258 的异文。** 稿件从 Munro 本（"potestas … voluntas"），而今天的通行读法是"voluntas … voluptas"。两种读法对理解卢克莱修的论证有一定的影响。建议请审读专家决定是否改从通行读法；如果改，需要一个可以合法使用的现代校勘本作依据（注 55）。
- **偏斜和具体选择的关系。** 稿件列出了两种读法（注 56）。
- **早期斯多亚派与"前激情"。** 盖利乌斯的材料是罗马时期的；早期斯多亚派是否已有明确的概念，稿件只指出有争论（注 44）。
- **阿尔克西拉乌斯和卡尔涅阿德斯的立场。** 是持有学说，还是纯粹辩证？稿件列出了两种理解（注 62、66）。
- **塞克斯都对学园派的描述。** 稿件说明这一描述有争议，并引了塞克斯都本人对阿尔克西拉乌斯的不同评价（1.232）。
- **怀疑派有没有信念。** 稿件介绍了"乡下人式"和"城里人式"之争，不作选择（注 71）。
- **古代问题与现代"自由意志"问题的关系。** 稿件介绍了博布齐恩和弗雷德的观点，但没有读到原著（注 58）。
- **第六部分的情境建议。** 三派的"建议"都是本章根据学说推想的，每一派内部的人也可能给出不同的建议；稿件在表前明确说明了这一点。
- **年代。** 除了 SEP 词条给出的几个年代，其他人物的生卒年都是通行的近似说法，没有逐一核对（注 1）。
- **课程名称。** 任务书给出的名称是"希腊化与罗马哲学：作为生活实践的哲学"；GR3 稿件的结语和导读称下一门课为"希腊化与罗马哲学：作为生活方式的哲学"，网站目录中的名称是"希腊化与罗马学派：作为生活的哲学"。本稿用任务书的名称。三处名称需要在 Phase 9B 统一；按任务书的限制，本阶段没有修改 GR3 和目录。
