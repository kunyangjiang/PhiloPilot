## 2. 涵盖的哲学问题与论证

- **导读。** 八个中心问题；"六种材料"表（亚里士多德原文、本章试译、转述、学者观点、本章的重构、本章编的例子）；贝克尔页码的解释；术语表；与上一门课和下一门课的关系。
- **第一部分：对柏拉图的批评。**
  - 《形而上学》Α 卷第 6 章的理型论起源故事，整理成五步表（987a32—b1；1078b27—32 苏格拉底与"分离"）；
  - 理型"既不是运动的原因，也不是变化的原因"（991a8—11）；"原型"与"空话和诗的比喻"（991a20—23）；
  - "第三人"论证：《巴门尼德篇》与《形而上学》的对照表，区分文献能说明的、亚里士多德自己的、现代学者重构的三层；
  - 《尼各马可伦理学》第一卷第 6 章对善的理型的批评（1096a16—17、1096b32—35）；
  - 普遍者不能是实体（1038b8—11），以及亚里士多德自己的"分离"实体（不动的推动者，1074b34），避免"柏拉图关心天上、亚里士多德关心地上"的简化。
- **第二部分：逻辑与证明。**
  - 《范畴篇》的"述说 / 在…之中"四分（1a20—25）和十范畴（1b25—27）；
  - 《解释篇》的陈述句与全称 / 单称（17a2—4、17a39—b1）；
  - 三段论的定义（24b18—20）、第一格（25b35—39、26a4—9）；有效性与真假的四种情况表；用替换词项证明无效；
  - 局限：存在含义、单称词项、命题逻辑的缺席（引向下一门课的斯多亚派）；卢卡西维茨与 Corcoran / Smiley 的两种解读；
  - 《后分析篇》：知识的定义（71b9—12）、证明的前提（71b20—25）、行星的例子（78a36—38）、"知道的理由"与"成立的原因"；第一原理与 nous（100b3—5）。
- **第三部分：实体与变化。**
  - "实体是什么"是最古老的问题（1028b2—4）；"是"的多种意思与"核心意义"（1003b5—7）；
  - 《范畴篇》的第一实体（2a11—14、2b5—6）及其标志（4a10—11）；
  - 巴门尼德问题与底层—缺乏—形式三要素（190b1—5）；变化的种类表；运动的定义（201a10—15）；
  - 质料与形式（铜像）、潜能与现实（1045b17—19、1048a32—35、1048b23—26、1049b5）；本章编的"共享单车"例子；
  - 《形而上学》Ζ 卷：实体的候选（1028b33—36）、形式作为第一实体（1029a27—30）；《范畴篇》与《形而上学》对照表；普遍形式 / 个别形式之争（据 SEP 列出两派学者）。
- **第四部分：四因与自然。**
  - 自然的定义（192b21—23）、形式比质料更是自然（193b8—11）；
  - 四因（194b23—34）、四因的解释性用法（198a24—27）；月食的例子（1044b12）；

  - 近代对目的因的批评（培根、笛卡尔、斯宾诺莎，只在注释中）；进化论提供的"第三种可能"。
- **第五部分：灵魂。**
  - 研究方法：愤怒的物理学定义与辩证法定义（403a30—b2）；
  - 灵魂的定义（412a6—9、412a19—28、412b11—22）："如果眼睛是动物"、斧子的思想实验；
  - 灵魂和身体是不是一（412b6—8）；可分离性的保留（413a3—7）；

  - 欲望与运动（433a18—21）；理智（429a22—25、430a1—2）与第三卷第 5 章的"主动的理智"（430a14—17、430a22—25）；"灵魂在某种意义上是一切"（431b21）；

## 5. 计划中的视觉与互动教学设计（只是计划，没有实现）

本阶段不做 React 实现。下面四个组件按建议的优先顺序排列。另有一个候选（灵魂能力），评估后不建议单独做，理由见 E。

### A. 三段论实验室（Syllogism Lab）

- **位置**：第二部分"有效与真：两件不同的事"之后，替代或补充"有效性与真假的四种情况"表；"行星"的例子之后可以再次调用。
- **目标**：让读者亲手体会"有效性只看形式"：同一个形式，换一组词项，前提真而结论假，就证明这个形式无效。第二步，区分"知道的理由"和"成立的原因"。
- **视觉构想**：三行句子槽（大前提、小前提、结论），每行由"量词（所有 / 有的 / 没有）＋ 词项 ＋ 是 / 不是 ＋ 词项"组成。右侧是三个圆的欧拉图（只用于全称和特称的简单情况）。下方一个"换词项"按钮。
- **学习者操作**：
  1. 从预设的几个例子中选一个（包括"所有狗都是动物；所有哺乳动物都是动物；所以所有狗都是哺乳动物"）；
  2. 按"换词项"：组件保持形式不变，从一个小词库中替换词项（例如把"哺乳动物"换成"猫"），显示前提和结论各自的真假；
  3. 在"行星"模式下，在"不闪烁"和"近"之间切换中词，看哪一个推论给出"为什么"。
- **反馈**：找到"前提真、结论假"的替换时，显示"这个形式无效"，并引出 24b18—20 的原文和本章试译；对有效的第一格形式，显示"无论怎样换词项，都找不到反例"，并注明"这是对有效性的说明，不是证明"。
- **学术把关**：
  - 只处理稿件讲过的第一格和"不分配的中词"一类常见错误，不做完整的三段论系统；
  - 欧拉图旁注明"现代的图示方法，不是亚里士多德的"；
  - 存在含义的问题只在"了解更多"中提示，不让组件在空词项上给出判定；
  - 词库只用日常、无争议的词。
- **移动端 / 桌面**：桌面为左右两栏（句子与图）；移动端改为上下排列，词项槽用下拉选择，不用拖动；欧拉图缩小为可展开的卡片；按钮不小于 44px。
- **最小实现**：一份例子 JSON（形式、词项、每对词项关系的真值表）；判定只对预设词库查表，不做一般的逻辑推理；欧拉图用三个 SVG 圆，位置按预设关系给定。不需要图形库。

### B. 质料、形式与变化探索器（Matter / Form / Change Explorer）

- **位置**：第三部分"变化的种类"表和"一个例子"之间（稿件中已经提到"本课计划中的'质料、形式与变化'互动演示"）。
- **目标**：让读者用"底层—缺乏—形式"三要素分析具体的变化，分清性质变化、位移、增减和实体的生成与消灭，并看到在每一种变化中什么持续存在。
- **视觉构想**：一张卡片表示一个事物（铜像、橡子、一个人、一辆共享单车），卡片分两层标注"质料"和"形式"。上方是变化的选择条；变化发生后，卡片的一部分改变，持续存在的部分保持高亮。
- **学习者操作**：
  1. 选择一个事物和一个变化（例如"人晒黑""铜像被熔化""橡子长成橡树""单车被拆成零件"）；
  2. 先自己判断变化的种类和"什么持续存在"；
  3. 按"看分析"，组件显示三要素：底层、缺乏、形式。
- **反馈**：答对时显示对应的原文（190b1—5 或 201a10—15）和本章试译；答错时只指出"持续存在的东西不对"或"种类不对"，再给一次机会。在"铜像被熔化"这一例中加一个说明：人工物的生成与消灭是亚里士多德常用的例子，但他认为人工物不是严格意义上的实体，这一点有讨论空间。
- **学术把关**：
  - 不把质料和形式画成"两层材料"（稿件明确说它们是分析的两个角度），图上用虚线和标签，而不是两种颜色的实体；
  - 不进入《形而上学》Ζ 卷普遍形式 / 个别形式之争；
  - "原初质料"不作为选项出现（稿件中没有展开这一有争议的概念）。
- **移动端 / 桌面**：桌面为三栏（事物、变化、分析）；移动端改为分步向导（选事物 → 选变化 → 作判断 → 看分析）。
- **最小实现**：一份"事物 × 变化"的 JSON（种类、底层、缺乏、形式、持续者、原文引用）；一个 React 组件管理选择状态；卡片用 CSS，不需要 SVG 动画。

### C. 四因工作坊（Four Causes Workshop）

- **位置**：第四部分"四种原因"之后、"自然中的目的"之前；第四部分的想一想可以复用这个组件。
- **目标**：让读者用四种"为什么"分析不同类型的事物，看到四因在人工物、生物和自然现象中的分布不同，并发现有的事物某一种原因不明显（如月食没有目的因，1044b12）。
- **视觉构想**：中央一张事物卡（房子、橡树、心脏、月食、一把椅子）；四周四个格子，分别是质料因、形式因、动力因、目的因。每个格子可以填入从选项中挑选的回答，也可以标记为"不适用"。
- **学习者操作**：
  1. 选一个事物；
  2. 为四个格子各选一个回答（例如房子的目的因："遮风挡雨"）；
  3. 对月食，判断目的因是否适用。
- **反馈**：逐格显示本章的说明；在"心脏"和"橡树"上，提醒"目的因在这里是内在的、不带意识的"，并引用 199a26—30；在月食上引用 1044b12。每一格旁有一个"现代科学怎么说"的折叠说明（例如心脏的功能解释），注明"这是现代的对照，不是亚里士多德的说法"。
- **学术把关**：
  - 不把目的因说成"设计者的意图"；
  - 不宣布"现代科学已经驳倒了目的论"或相反，只把"偶然或目的，二者必居其一"这一步标为"可以质疑"；
  - 事物卡只用稿件中出现过的例子，加上想一想中提到的椅子。
- **移动端 / 桌面**：桌面为十字形布局（事物在中，四因在四边）；移动端改为纵向的四张卡片，逐张填写。
- **最小实现**：一份事物 JSON（每种原因的选项、正确项、说明、原文引用）；一个纯 React 组件；布局用 CSS 网格。

### D. 德性与中道探索器（Virtue & Mean Explorer）

- **位置**：第六部分"中道"一节，"相对于我们的中间"之后；可以替代德性与恶的表格。
- **目标**：纠正"中道就是凡事适度"的误解：中道相对于人和情况，由有实践智慧的人规定；有的感受和行为根本没有中道（1107a8—12）。
- **视觉构想**：一条横轴（不足—中道—过度），例如"愤怒"。上方是一组情境卡（朋友开了一个无心的玩笑；弱者在你面前受辱；同事抢了你的功劳）。选定情境后，轴上的"恰当区间"移动和变宽。
- **学习者操作**：
  1. 选一种感受或行为（愤怒、恐惧、给予）；
  2. 选一个情境，在轴上拖动标记，表示自己认为恰当的程度；
  3. 再看"五个'应当'"的分解：何时、对何事、对何人、为何目的、以何种方式（1106b21—23）。
- **反馈**：显示本章对该情境的说明，以及恰当区间为什么移动（例如对弱者受辱，强烈的愤怒可以是恰当的）；在米隆的例子中显示 1106b3—4 的短语。选到"通奸""谋杀"等没有中道的项目时，轴消失，显示 1107a8—12 的原文和本章试译。
- **学术把关**：
  - 组件不给出"正确数值"，恰当区间只是示意，标注"由实践智慧规定，不是可以计算的点"；
  - 情境说明使用"本章的看法"这样的措辞；
  - 不把读者的选择记录或评分；这里有判断的空间，标为观点性的练习。
- **移动端 / 桌面**：桌面为轴在上、情境卡在下；移动端用滑块代替拖动标记，情境卡改为横向滑动。
- **最小实现**：一份 JSON（感受 / 行为、情境、恰当区间的起止百分比、说明、原文）；一个 SVG 横轴和一个受控滑块。不需要图形库。

### E. 灵魂能力（Soul Functions）：不建议单独做

- **评估**：设想过一个"生物—能力"矩阵组件（植物、不能移动位置的动物、能移动的动物、人 × 营养、感知、欲望、位移、理智）。不建议单独做，理由是：
  - 稿件中的能力表已经清楚，互动只是把表格变成点选，不增加理解；
  - 第五部分真正的难点在"第一实现 / 第二实现"、蜡与印记、主动的理智，这些更适合用练习题来处理（见第五组）；
  - 一个"有 / 无"的矩阵会把层级关系（较高的能力以较低的能力为前提，414b28—32，稿件转述）简化成独立的勾选。
- **如果产品负责人仍然希望做**：可以改成一个"层层包含"的同心圆 SVG，点击每一层显示对应的原文，并附上"如果眼睛是动物"的思想实验卡片。最小实现是一个静态 SVG 加一份层级 JSON。
