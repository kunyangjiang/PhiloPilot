# PhiloPilot — 梵、自我与世界：吠檀多派 (IN6) image approval sheet

> Prepared 2026-11-09 for the Product Owner from the Phase 17A shortlist (`IN6_PRODUCTION_REPORT.md` §8). **Nothing has been downloaded or embedded, and there are no placeholders.** The course is fully integrated without images. Each candidate needs an explicit decision (approve / reject / hold). After approval, each file would be downloaded once, inspected, recorded in `public/media/in6/SOURCES.md` and credited in its caption.

Metadata, including the direct URLs below, was read again from the Wikimedia Commons API (`imageinfo`, `extmetadata`) on 2026-11-09. It matches the Phase 17A record. Rights are given **as the source states them**; this sheet does not claim that any use is legally cleared. There is no period portrait of Śaṅkara, Rāmānuja or Madhva: every image of them is a later devotional or artistic work, and a caption must say so.
