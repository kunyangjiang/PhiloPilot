## 2. 涵盖的哲学问题与论证

- **自然解释的出现。**
  - 赫西俄德的谱系式解释与米利都人的构成式解释。
  - 泰勒斯：区分亚里士多德的证言与他的推测（"ἴσως"）。
  - 阿那克西曼德 B1：讨论残篇边界的问题，以及他关于大地的"没有理由移动"论证。
  - 阿那克西美尼：疏密变化是一种可以想象的机制，"哈气"的经验及其局限。
  - 色诺芬尼：以发生学方式批判神人同形论，说明这种论证的限度（来源不等于为假），以及他关于知识限度的反省。
  - 对"从神话到理性"框架的三点批评。正面的结论是：公开的批评传统。
- **变化问题。**
  - 赫拉克利特：B12 与 B91 的版本问题，以及两种版本的哲学后果；尺度、逻各斯、对立统一；亚里士多德本人对"赫拉克利特否认矛盾律"的保留。
  - 巴门尼德：
    - 两条道路和"ἔστιν"的歧义（存在、谓述、模态几种读法）；
    - 八步重构和论证图；
    - 理性与感官的关系；
    - 三类反驳或读法：歧义、思想的对象、"元原则"读法。
  - 芝诺：归谬法；二分法、阿喀琉斯、飞矢三个悖论；亚里士多德的回应与现代回应，以及尚未解决的部分（超级任务）。
- **多元论与原子论。**
  - 恩培多克勒：四根，爱与恨。
  - 阿那克萨戈拉：一切在一切之中，心灵，以及《斐多》中的抱怨属于目的论标准。
  - 原子论：虚空作为"存在的不存在者"；形状、排列、位置；B9"按约定 / 实际上"；B125 感官对理智的反驳；与现代原子论的四点差异。
- **智者。**
  - 职业而非学派，史料多出自敌对的一方。
  - 普罗泰戈拉 B1 的三种读法、自我推翻论证及其关键一步、"较好而不是较真"的回应、B4。
  - 高尔吉亚：《论不存在》（论证还是戏仿），《海伦颂》中言辞与药物的类比，柏拉图对修辞的批评。
  - 约定与自然：希罗多德 3.38、安提丰、卡利克勒、色拉叙马霍斯（区分文学人物与历史人物），以及普罗泰戈拉的神话。
  - 美德能否教授。
- **苏格拉底。**
  - 苏格拉底问题：阿里斯托芬、柏拉图、色诺芬、亚里士多德各自的立场；亚里士多德《形而上学》M.4 的证言；发展论及其所受的质疑。
  - 诘问法的六步模式，与讲课的区别，弗拉斯托斯的"诘问法问题"。
  - **《拉凯斯》的七步导读**：从例子到普遍定义，"坚忍"，"明智的坚忍"，反例，（甲）（乙）（丙）三个信念的矛盾，尼基阿斯的定义，以及"全部美德"的矛盾。
  - 美德的统一性（彭纳与弗拉斯托斯）。
  - 美德即知识，不自制（akrasia），亚里士多德的批评。
  - 追问的界限：定义优先、羞辱感、只破不立、反讽。
- **审判。**
  - 《申辩》不是庭审记录。
  - 罪名；两组控告者；与自然哲学家和智者的混同。
  - 神谕；21d 的原话与"我唯一知道的是我一无所知"之间的区别；弗拉斯托斯区分两种知识。
  - 盘问梅勒图斯：驯马的类比；骡子的论证，以及这个论证没有回答的问题。
  - 岗位与死亡；"服从神而不服从你们"；关心灵魂；牛虻。
  - 神灵之声；阿吉纽西与勒翁两事；政治背景（大赦，克里底亚与亚西比德，埃斯基涅斯 1.173）。
  - 量刑；38a"未经省察的人生不值得过"的上下文及其适用范围。
  - 关于死亡的两种可能，以 42a 的不确定作结。
  - 与《克里同》之间的张力，以及通向下一门课《柏拉图：知识、灵魂与正义之城》的桥梁（从《游叙弗伦》讲起）。

## 5. 计划中的视觉与互动教学设计（只是计划，没有实现）

### A. 希腊世界的地点与年代（Greek World Context Explorer）

- **位置**：导读末尾（"读这一章的几点提醒"之后），第三、四部分开头可以再次调出。
- **目标**：让读者看清这些思想家分布在伊奥尼亚、南意大利、西西里、色雷斯和雅典，认识到"希腊哲学"一开始并不在雅典；同时看到年代上的先后与重叠，以及年代的不确定性。
- **视觉构想**：用本课自绘的简化 SVG 地图标出东地中海的海岸线和约十个城市（米利都、以弗所、科洛丰、克拉佐美奈、埃利亚、阿克拉伽斯、阿布德拉、莱昂蒂尼、雅典），旁边配一条年代轴。年代用**区间条**表示，不用一个点，区间两端渐隐，表示不确定。
- **学习者操作**：点击城市，高亮该城的人物及其年代条；点击年代条，在地图上显示所在城市。有一个"只看活动于雅典的人"的开关。
- **反馈**：每位人物的卡片显示一句话的身份、年代依据（例如"据柏拉图《巴门尼德篇》推算"）和一个"在本章哪一节"的链接。
- **学术把关**：
  - 年代一律写区间并注明依据；
  - 不画影响箭头，不画"师承线"，师承关系只在卡片中注明"古代传统说……"；
  - 不标"哲学起源地"之类的字样。
- **移动端**：地图在上，年代轴在下，两者纵向排列；城市点击区域不小于 44px；人物卡片以底部抽屉形式出现。
- **最小实现**：一张静态 SVG 加一份 JSON 人物表（城市、年代区间、依据、章节锚点），用 React 状态控制高亮。不需要地图库，也不需要网络图块。

### B. 巴门尼德论证探索器（Parmenides Argument Explorer）

- **位置**：第二部分"一步一步重构巴门尼德的论证"，可以替换或补充其中的 mermaid 图。
- **目标**：让读者亲手检查论证的每一步，发现"是"的歧义怎样影响论证能否成立。
- **视觉构想**：八个步骤卡片纵向排列，卡片之间用连线表示推出关系。每张卡片可以展开，显示对应的希腊原文短句（已核对过的 B2、B3、B8 诗行）和本章试译。
- **学习者操作**：
  1. 在顶部选择"它是"的读法："存在"、"是某某"或"必然是"。
  2. 对每一步选择"接受"或"质疑"。
  3. 质疑某一步时，下游依赖它的步骤变成灰色虚线，表示结论不再得到支持。
- **反馈**：切换读法时，第 2、4、5 步的说明文字随之改变，并提示在这种读法下，哪一步最容易受到质疑。所有提示都标明是"本章的重构"。
- **学术把关**：
  - 卡片顶部固定显示"这是本章根据残篇所作的重构，不是巴门尼德的原文"；
  - 三种读法只写成读法的类型，不写成某位学者的定论，学者的名字只在"了解更多"中出现，并链接到注释；
  - 不给出"正确的读法"。
- **移动端**：卡片单列显示；读法选择器固定在顶部，做成可横向滚动的分段控件；连线简化为左侧的竖线和缩进。
- **最小实现**：一个包含步骤、依赖关系和各读法说明文字的 JSON 数据，加一个纯 React 组件，依赖关系用一个简单的图遍历来计算。不需要图形库。

### C. 变化与同一的演示（Change and Persistence Demonstration）

- **位置**：第二部分"河流残篇"之后。第三部分"变化即重新排列"可以复用同一组件的第二种模式。
- **目标**：对比三种回答"同一个东西怎样在变化中保持同一"的思路：B12 读法（同一靠流动维持）、巴门尼德（真正的存在不变）、原子论（不变的单位重新排列）。
- **视觉构想**：一个简单的动画区域，分三种模式：
  1. "河流"：水粒子流过固定的河道，计数器显示"已经换过的水"所占的比例，河道轮廓不变；
  2. "存在者"：一个静止的整体，外面有一层"感官印象"在变化，可以开关；
  3. "原子"：十几个几何形状重新排列成两三种图案，每个形状本身始终不变。
- **学习者操作**：切换模式；拖动时间滑块；回答一个问题："这里什么变了？什么没变？"，在"组成部分""结构或形式""整体"三项中勾选。
- **反馈**：勾选后显示该思想家的回答和对应残篇的链接，同时附一句"这个演示的限度"（例如：河流模式中的水粒子是本课画的，赫拉克利特没有粒子的概念）。
- **学术把关**：
  - 每种模式都标明是"本课的示意"；
  - 原子模式不显示颜色（呼应 B9），并注明古代原子论与现代原子论的区别；
  - 不把赫拉克利特简化为"万物皆流"。
- **移动端**：动画区域按 16:10 比例自适应；"减少动态效果"设置开启时改为三帧静态图；勾选区放在动画下方。
- **最小实现**：使用 CSS/SVG 动画或 requestAnimationFrame 绘制少量元素，不需要物理引擎；三种模式共用一个组件。

### D. 苏格拉底对话工作坊（Socratic Dialogue Workshop）

- **位置**：第五部分《拉凯斯》七步导读的开头；或者放在导读结束后，作为整段导读的互动版本。
- **目标**：让读者站在拉凯斯的位置上，体验"同意的命题"怎样一步步累积成矛盾，从而理解诘问法与讲课的区别。
- **视觉构想**：左边是对话气泡（苏格拉底、拉凯斯、尼基阿斯），右边是一块"你已同意的命题"面板。命题以卡片的形式累积，卡片之间出现冲突时，用红色连线标出。
- **学习者操作**：在苏格拉底的每个问题处选择"同意"或"不同意"，选项是固定的，不写自由文本。
  - 选"同意"时，沿着柏拉图原文的路线推进；
  - 选"不同意"时，显示一条"如果你不同意，苏格拉底可能会这样追问"的旁支说明，这是本课所写的示意，并明确标出，然后回到主线。
  - 出现矛盾时，读者要选择放弃（甲）、（乙）、（丙）中的哪一个。
- **反馈**：放弃某一项后，显示这样做的代价，以及后来的哲学家里谁走了这条路（例如，美德统一性的两种读法）。不评对错。
- **学术把关**：
  - 主线的每一句都对应《拉凯斯》的斯特方码，可以展开查看已核对的希腊原文短句；
  - 旁支对话明确标为"本课虚构的示意"，与柏拉图的文本在视觉上区分开（不同的底色，加"示意"标签）；
