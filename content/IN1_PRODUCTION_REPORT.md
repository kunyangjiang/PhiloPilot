## 3. Main uncertainties

The full list is in the manuscript's 《来源与权利说明》. The most important:

1. **Dates.** All are approximate: Ṛgveda, early Upaniṣads, Mahāvīra, and the redaction of DN 2.
2. **Cārvāka.** The section rests on a single article, read from a PDF whose text could only be partly recovered. The "fermentation" analogy has no source the course could check. The critics' reconstruction of the argument against inference, as given in the Sarvadarśanasaṅgraha, was not read in the original.
3. **Jain material.** It all comes through SEP, apart from DN 2 and Ud 6.4. Open items:
   - the numbering of Tattvārthasūtra 5.29/5.30 (to be checked against a critical edition);
   - the Pārśva "four restraints" tradition, which still lacks a source;
   - the meaning of *vāri* in DN 2.
4. **Ājīvikas.** Only DN 2 was used. Basham (1951) and the Jain accounts were not read.
5. **Interpretations not tied to named scholars.** These are summarised as common readings and marked as such in the notes:
   - three readings of the Nāsadīya;
   - two evaluations of Gārgī's silencing;
   - the historical meaning of ChU 5.3.7.
6. **GRETIL reuse terms.** GRETIL says its texts are "for reference purposes only", and the terms of the source file (Sansknet) still need to be confirmed. Only short passages are quoted.

## 4. Items needing Product Owner attention

1. **Expert review before publication.** The weakest points are the Cārvāka sources, the Jain textual details and the Brāhmaṇa coverage. These are the areas where an Indologist's review matters most.
2. **Brāhmaṇa depth.** Add a Śatapatha Brāhmaṇa passage (for example on the fire altar), or accept BĀU 1.1 as the representative example. Adding one would need a further reading session.
3. **Chinese names.** I used classical Buddhist transliterations for the six teachers and common phonetic forms for the Upaniṣadic figures. There is no standard rendering, so please confirm a house style.
4. **The word 邪命外道.** It is the conventional Chinese term, and the text explains its pejorative 邪. A neutral alternative such as 阿耆毗伽派 is possible.
5. **Critiques & Responses.** No optional 后世批判与回应 section was written. Indologists' later critiques of how these traditions were received in the West (for example the "Hinduism as Vedānta" lens) would need sources that have not been read. The main text already covers the documented debates.
6. **Length.** Body text is about 29,400 characters, about three times the illustrative range. The spec sets no limit, so no cuts were made.

### 5.1 Upaniṣadic Dialogue Explorer (奥义书对话探索器)

- **Insertion:** Part II, after the Indra–Virocana section, before the ātman/brahman table (`mediaAfter('IN1', '二、…', 'heading:自我（ātman）与梵（brahman）…')`).
- **Objective:** read the four dialogues as arguments. The learner should be able to see which move is a claim, an example, an objection, a rejection or a threat, and where each dialogue's reasoning is weakest.
- **Visual:** four horizontal tracks: Uddālaka 6.1–13, Maitreyī 2.4, Gārgī 3.6/3.8, Indra 8.7–12. Each move is a node, labelled by its kind with a text tag and a line style; colour is never the only signal. Selecting a node opens a panel with:
  - the reference;
  - the Sanskrit (collapsible);
  - the course translation;
  - one line on what the move does.
- **Interactions:**
  - pick a track and step through it with the arrow keys or the Next button;
  - at each objection node, an optional single-choice "what comes next?" prediction, revealed after the learner commits;
  - a toggle that shows only the moves that do argumentative work.
- **Specific safeguards:**
  - each track is headed by a fixed note: "文本中的人物形象，不是历史记录";
  - the Gārgī track shows the threat (3.6.1) and the later answer (3.8.8) as two separate moves, so neither reading of the silencing is preferred;
  - the dialogue moves are fixed to the manuscript's existing data.

```tsx
// Minimal concept: data-driven tracks, SVG nodes, text tags for move types.
type Move = { ref: string; kind: 'claim' | 'example' | 'objection' | 'reject' | 'threat'; zh: string; sa?: string };
const TRACKS: Record<string, Move[]> = {
  indra: [
    { ref: '8.7.4', kind: 'claim', zh: '答案一：眼中、水中、镜中的人影' },
    { ref: '8.9.1', kind: 'objection', zh: '身体瞎它也瞎，身体死它也死' },
    // …each move taken from the manuscript, not newly written
  ],
};
export function DialogueTrack({ id }: { id: keyof typeof TRACKS }) {
  const moves = TRACKS[id]; const [i, setI] = useState(0);
  return (<figure>
    <svg viewBox={`0 0 ${moves.length * 120} 60`} role="list">
      {moves.map((m, k) => (<g key={k} role="listitem" transform={`translate(${k * 120},10)`}
          onClick={() => setI(k)} aria-current={k === i}>
        <rect width="104" height="40" className={`mv mv--${m.kind}`} />
        <text x="8" y="24">{m.ref} · {LABEL[m.kind]}</text></g>))}
    </svg>
    <MovePanel move={moves[i]} />
  </figure>);
}
```

### 5.2 Self and Reality Comparison (自我与实在对照)

- **Insertion:** Part VI, replacing the static "positions × questions" table, which stays as the no-JS fallback.
- **Objective:** compare rival positions question by question, and notice where a position says nothing at all.
- **Visual:** a matrix with seven positions as rows and four questions as columns. Each cell shows a short summary and a source-tier badge. Cells where the position does not address the question are shown as "不是主题", not left blank.
- **Interactions:**
  - pin any two rows for a side-by-side view;
  - pick one question column to reorder the rows by type of answer, without ranking them;
  - each cell expands to the manuscript's passage and note.
- **Specific safeguards:**
  - a fixed caption reads "这组问题是本章提出的，不是各派共有的框架；相似不等于影响";
  - the Ājīvika row and the Pūraṇa, Pakudha and Sañjaya row carry the "据佛经转述" badge in every cell.

```tsx
type Tier = '原典' | '二手转述' | '本章重建';
type Cell = { text: string; tier: Tier; ref?: string } | null; // null renders "不是主题"
const QUESTIONS = ['自我', '业与再生', '解脱或目标', '知识来源'] as const;
export function Compare({ rows }: { rows: { name: string; cells: Cell[] }[] }) {
  const [pinned, setPinned] = useState<number[]>([]);
  const shown = pinned.length === 2 ? pinned.map((i) => rows[i]) : rows;
  return (<table className="cmp"><thead><tr><th />{QUESTIONS.map((q) => <th key={q}>{q}</th>)}</tr></thead>
    <tbody>{shown.map((r, i) => (<tr key={r.name}>
      <th><button aria-pressed={pinned.includes(i)} onClick={() => toggle(i)}>{r.name}</button></th>
      {r.cells.map((c, j) => <td key={j}>{c ? <>{c.text}<span className="tier">{c.tier}</span></> : '不是主题'}</td>)}
    </tr>))}</tbody></table>);
}
```

### 5.3 Jain Many-Sidedness Explorer (多面性探索器)

- **Insertion:** Part IV, after "第三步：七种谓述", before "多面性是不是相对主义？".
- **Objective:** see that each of the seven predications is true *relative to a stated parameter of the object*, which is why the doctrine is not relativism. The explorer also contrasts it with Sañjaya's refusal to answer.
- **Visual:** a simple SVG pot, described as "a red pot" following SEP's example, with four parameter chips: material (自身材料), place (位置), time (时间) and state (状态). The seven predications are listed as rows, and each row shows true or false for the current choice, together with a one-line reason.
- **Interactions:**
  - set the parameter for the "exists" side and the "does not exist" side, for example "as clay" against "as a blue pot";
  - rows 3–7 update as combinations of rows 1, 2 and 4;
  - a three-way toggle shows how the same question is handled by syādvāda (qualified assertion), relativism ("true for you", shown as a contrast the Jains would reject) and Sañjaya's vikkhepa (no assertion).
- **Specific safeguards:**
  - a header note says: "七种谓述是后来（萨曼塔跋陀罗等）的系统学说，不是大雄的原话";
  - the relativism panel is clearly marked as a non-Jain contrast;
  - the explorer uses only the pot example from SEP and the course's own hot-and-cold-water example, already labelled in the manuscript;
  - no Sanskrit is shown apart from *syāt* and the seven-line schema already in the manuscript.

```tsx
const BHANGA = ['存在', '不存在', '存在又不存在', '不可言说', '存在，且不可言说', '不存在，且不可言说', '存在又不存在，且不可言说'];
export function Saptabhangi() {
  const [own, setOwn] = useState('就其材料（泥土）而言');
  const [other, setOther] = useState('作为一个蓝色的罐子');
  return (<figure><PotSVG />
    <ParamChips label="“存在”一侧" value={own} onChange={setOwn} />
    <ParamChips label="“不存在”一侧" value={other} onChange={setOther} />
    <ol>{BHANGA.map((b, k) => <li key={k}>从某方面说，它{b}<small>{reason(k, own, other)}</small></li>)}</ol>
  </figure>);
}
```

### 5.4 Knowledge and Evidence Workshop (知识与证据工坊)

- **Insertion:** Part V, after the table that sets the critics' Cārvāka beside Bhattacharya's reconstruction.
- **Objective:** see how the verdict on "you reject inference, yet you infer" changes with the version of Cārvāka, and practise drawing the line between testable and untestable inference.
- **Visual:** four claim cards:
  - 远处有烟，所以那里有火;
  - 明天太阳会升起;
  - 人死后有来世;
  - 意识依赖于身体.

  There are two columns, one for each version (批评者笔下 and Bhattacharya 重建), and three bins: 感知, 以感知为基础的推理, 关于不可感知之物的推理.
- **Interactions:**
  - drag or keyboard-select each card into a bin;
  - each column then shows whether that version of Cārvāka accepts the claim as knowledge;
  - the fourth card is a contested question: it shows the strengths and costs of each placement and marks none as correct.
- **Specific safeguards:**
  - only the smoke–fire example is attested in the source (Purandara's *lokaprasiddha anumāna*); the other cards are labelled "本章设想的例子";
  - the Humean comparison appears only as "结构上的比较，没有历史联系".

```tsx
type Bin = 'perception' | 'grounded' | 'unperceivable';
const CARDS = [{ id: 'smoke', zh: '远处有烟，所以那里有火', attested: true }, /* … */];
const VERDICT: Record<'critic' | 'bhattacharya', Record<Bin, boolean>> = {
  critic: { perception: true, grounded: false, unperceivable: false },
  bhattacharya: { perception: true, grounded: true, unperceivable: false },
};
```
